# Arco Design React 2.66.20 (fork)

This patch release completes the fork's Progress and Spin improvements and restores reproducible CI installs.

## Highlights

- Adds accessible names and value text to Progress and clamps progress values to the supported 0–100 range across line, steps, and circle variants.
- Respects `prefers-reduced-motion` for Progress animations.
- Reschedules the Spin loading delay when either the loading state or delay changes.
- Records all package dependency ranges in `yarn.lock`, allowing CI to use frozen installs.

## Upgrade

Install `@arco-design/web-react@2.66.20` with npm or Yarn. No migration is required; the Progress accessibility props are optional and existing APIs remain compatible.
