# Arco Design React 2.66.22 (fork)

This patch release updates vulnerable build and site dependencies. It is distributed through GitHub Releases and is not published to npm.

## Changes

- Updates `tar` to 7.5.18, the `node-notifier` UUID dependency to 11.1.1, and the site `image-size` dependency to 2.0.3.
- Keeps the legacy Less/PostCSS build path working while applying the dependency updates.
- Updates the site lockfile and preserves the existing React 16-19 support and release verification workflow.

## Security status

This release resolves the reported advisories addressed by the dependency updates above. It does not clear every open Dependabot alert. Remaining alerts involve legacy Webpack 4/Storybook 6 tooling, older SVGO/PostCSS/UUID transitive paths, and packages without a patched version. Forcing incompatible major versions into those paths would risk breaking the build; they require a compatible toolchain migration or upstream fixes.

## Installation

Fork releases are distributed through GitHub Releases. The npm package named `@arco-design/web-react` is the upstream package and may differ from this fork.

```bash
npm install https://github.com/yuchen0x1/arco-design/releases/download/v2.66.22/arco-design-web-react-2.66.22.tgz
```

Verify `SHA256SUMS` and the build attestation from the release page before production use.

## React 16-19 compatibility

- React 16/17 use `ReactDOM.render`.
- React 18/19 use `createRoot`.
- React 19 applications using imperative `Message`, `Notification` or `Modal` must import `@arco-design/web-react/es/_util/react-19-adapter`.

The peer range remains `react >=16`. The release gate installs the packed tarball against React 16.14.0, 17.0.2, 18.3.1 and 19.2.0 and runs an SSR/import smoke test for each.

## Update notifications

The package has no in-app update checker. Follow this repository's GitHub Releases to receive release notifications. The documentation site's service-worker prompt only announces updated site content and does not check versions in consumer applications.
