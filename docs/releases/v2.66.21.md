# Arco Design React 2.66.21 (fork)

This patch release fixes React lifecycle edge cases, improves accessibility, and updates the fork's CI and release process. It does not change public component APIs and is not published to npm.

## Changes

- Keeps `useMessage` and `useNotification` instances stable across parent re-renders and queues `useNotification` calls until the context holder mounts.
- Prevents `useUpdate` from firing during React 18 StrictMode's first effect cycle and removes `Form.Item` state updates during unmount.
- Stops InputNumber from emitting non-finite `aria-valuemin` and `aria-valuemax` values, marks controlled out-of-range values with `aria-invalid`, adds labels to Alert and Table expand controls, and renders Message and Notification close controls as labeled native buttons while keeping interactive custom `closeIcon` nodes un-nested.
- Adds an effective `prefers-reduced-motion` fallback and visible keyboard focus styles for the affected controls.
- Updates CI to Node.js 22, changes release attestation verification to use the pushed tag, disables npm publishing for this fork, and corrects package metadata.
- Keeps `react-is` on 18.x (React 19 detection is handled internally) and adds a React 16/17/18/19 consumer SSR matrix to CI.

## Installation

Fork releases are distributed through GitHub Releases. The npm package named `@arco-design/web-react` is the upstream package and may differ from this fork.

```bash
npm install https://github.com/yuchen0x1/arco-design/releases/download/v2.66.21/arco-design-web-react-2.66.21.tgz
```

Verify `SHA256SUMS` and the build attestation from the release page before production use.

## React 16–19 compatibility

- React 16/17 use `ReactDOM.render`.
- React 18/19 use `createRoot`.
- React 19 applications using imperative `Message`, `Notification` or `Modal` must import `@arco-design/web-react/es/_util/react-19-adapter`.

The peer range remains `react >=16`. The release gate installs the packed tarball against React 16.14.0, 17.0.2, 18.3.1 and 19.2.0 and runs an SSR/import smoke test for each; React 18 also has a separate manually dispatched full test workflow.

## Known limitations

- This fork has no npm publication; use the GitHub Release archive for prebuilt installs.
- The consumer matrix verifies installation and SSR only; a full behavioral test run for React 18/19 is not part of the tag-triggered gate.
- React 19 requires the adapter import noted above for imperative overlays.
- Interactive custom `closeIcon` nodes keep their original span wrapper to avoid nested interactive markup; consumers should supply icon-only nodes for the native button path.

No component API migration is required.
